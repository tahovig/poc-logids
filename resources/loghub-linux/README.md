# loghub Linux dataset sample

`Linux_2k.log` — a 2,000-line sample of real production syslog data (includes genuine SSH
brute-force activity), fetched 2026-07-17 from:

https://raw.githubusercontent.com/logpai/loghub/master/Linux/Linux_2k.log

Source project: [logpai/loghub](https://github.com/logpai/loghub) — real-world log datasets
collected from production systems, freely available for research/academic use. The full
dataset (263.9 days / 25,567 lines) is available via the Zenodo link in that repo; only the
2k-line sample is vendored here for demo/testing purposes.

If you use this data, cite the loghub project per its repository's guidance.
